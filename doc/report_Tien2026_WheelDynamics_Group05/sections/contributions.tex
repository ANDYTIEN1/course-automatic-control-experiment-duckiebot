\label{sec:ai-use}

We used Claude (Anthropic) as an assistant throughout the experiment. It guided us through the lab procedure, tracked the videos and processed the data with the course scripts, wrote the tracking options and the case-study changes (pull request \#9), produced the figures and the numbers of \texttt{results.tex} with the course scripts, set up this report from the template, compiled it, and checked our sections against the data.
